Prove private Grocery MCP connectivity

Win: prove that Hermes can reach Grocery MCP by Docker DNS without publishing Grocery MCP to the host.

1. Identify the containers and networks

docker ps --format 'table {{.Names}}\t{{.Image}}\t{{.Networks}}'

Hermes and grocery-mcp must share the private agent_internal network. Grocery MCP may also have an egress network for retailer APIs.

2. Test from inside Hermes

docker exec HERMES_CONTAINER python -c "import urllib.request; print(urllib.request.urlopen('http://grocery-mcp:8000/health').read().decode())"

The checkpoint passes only when the response is {"status":"ok"}. A host-side response does not prove that Hermes can resolve or reach the service.

Why this matters

The MCP endpoint has no authentication. The private Docker network is therefore part of the security boundary, not merely plumbing. Do not publish port 8000.
