# Hermes discovered the bounded Grocery MCP surface

Hermes connected to Grocery MCP over Streamable HTTP with no application credentials and discovered exactly the nine allowlisted tools. This confirms both protocol compatibility and that Hermes-side filtering excludes any accidental future MCP surface expansion until explicitly reviewed.

**Evidence:** `hermes mcp test grocery` connected successfully and listed the nine expected search, comparison, cart, proposal, and health tools.
